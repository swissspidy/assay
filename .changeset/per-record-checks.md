'@swissspidy/assay': minor
---

Checks can now say that a value belongs to one record. A new `each` assertion finds the records a locator matches (rows, list items, articles; a term together with the definitions that follow it, as in a `dt` with its `dd`s) and requires a nested assertion to hold inside each of them; locators and text sources inside it resolve within the record, so a value shown in another row or under another term no longer satisfies the check. The `items` normalizer takes `pick`, a list of JSON Pointers, to keep several fields of each item together, so two collections whose items carry different fields can still be compared record by record; `validateCheckSet` warns about `pick` between one collection before and after the task (same fields, so the dropped ones could change), and the compiler refuses `pick` whenever both collections' items have the same fields. `validateCheckSet` warns about a check that reads a definition found by its own content rather than through its term (the compiler refuses it), and rejects reads inside `each` that do not depend on the record. Stress testing swaps the values a record check reads with another record's, moves them out of the record, swaps one field between two JSON records, and reorders term groups as a valid variant. Existing check sets validate and evaluate as before.
